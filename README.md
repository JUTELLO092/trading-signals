# Trading Signals

Plataforma de analisis y senales de trading inteligentes.

## Despliegue en Vercel

1. Forkea este repositorio o conectalo directamente a Vercel
2. Vercel detectara automaticamente Next.js
3. Click en Deploy
4. Listo!

## Uso

- El dashboard muestra senales de COMPRA/VENTA/MANTENER para los principales activos
- Los indicadores tecnicos (RSI, MACD, SMA) se calculan en tiempo real
- Datos via Yahoo Finance (actualizacion cada 5 minutos)

## Stack

- Next.js 14
- React 18
- Recharts
- Tailwind CSS
- Desplegado en Vercel
